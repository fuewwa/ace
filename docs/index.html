A floating window manager that gets out of the way.

ace is a minimal X11 window manager written in C++17. No tiling to fight, no compositor bloat — just windows you move and resize by hand, and a footprint of about 5MB of RAM.

Install

ace needs a C++17 compiler and libX11. Pull the headers for your distro, then build.

arch linux
$ sudo pacman -S libx11 xorg-server-xephyr
debian / ubuntu
$ sudo apt install libx11-dev xserver-xephyr
build & try it
$ git clone https://github.com/fuewwa/ace
$ cd ace && sudo make clean install
run it by default
$ echo 'exec /path/to/ace' >> ~/.xinitrc
$ startx
